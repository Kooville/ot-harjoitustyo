# Käyttöohje

Lataa projektin viimeisin release.

## Ohjelman käynnistys

1. Asenna riippuvuudet siirtymällä repositorioon ja suorittamalla komennon:

```bash
poetry install
```

2. Alusta tietokanta komennolla:

```bash
poetry run invoke build
```

3. Käynnistä sovellus komennolla:

```bash
poetry run invoke start
```
